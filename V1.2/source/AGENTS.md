## Agent skills

### Issue tracker

Track specifications and implementation issues as local Markdown under `.scratch/`. Read `docs/agents/issue-tracker.md` before creating or updating them.

### Triage labels

Use the repository's five canonical local triage states. Read `docs/agents/triage-labels.md` before changing a ticket status.

### Domain docs

Use the single-context domain layout at the repository root. Before domain-sensitive work, read `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist; see `docs/agents/domain.md`.
