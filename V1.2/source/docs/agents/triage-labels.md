# Triage labels

Use these canonical role strings as local ticket statuses:

| Canonical role | Local status | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | More information is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for implementation. |
| `ready-for-human` | `ready-for-human` | Requires a human-only action or decision. |
| `wontfix` | `wontfix` | Will not be implemented. |

When a skill names a canonical role, write the matching local status exactly as shown.
