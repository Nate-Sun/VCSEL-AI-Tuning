**Goal:** Add a pre-authorized `PILOT_3_THEN_FAST24` real-hardware execution path to Native V1.2 with killable DCA I/O, exact readback, durable Dataset evidence, and verified B0 recovery.

**Architecture:** Selectively migrate the reviewed V1.1.1 optimization engine and DCA process-safety behavior at `e7f08eb7f1e0c79eb17f94c037c6db6e23c5d1e9`, then adapt them behind Native V1.2's existing AI execution factory, TaskStore, Dataset writer, continuous FIR, runtime configuration, and compatibility API. **Tech Stack:** Python 3.11+, FastAPI, Pydantic, SQLite TaskStore, NumPy, PyVISA adapters, Windows `multiprocessing` spawn, React, TypeScript, Vitest, Playwright, pytest.
