# V1.1 READ_ONLY Hardware Assembly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble a reviewed READ_ONLY runtime into a production V1.1 gateway and runner that capture a complete dynamic B0 only during explicit Preflight and can never mutate hardware.

**Architecture:** Add a focused `read_only_runtime` module with a lazily opened driver bundle, a query-only gateway, and a rejecting runner. Update `create_runtime` to select this pair for READ_ONLY after cross-validating duplicated runtime/profile endpoints; leave LIVE_TUNING external factories unchanged.

**Tech Stack:** Python 3.13, dataclasses/protocols/context managers, Pydantic runtime config, existing FlexDCA/VD1124/VIT drivers, pytest spy drivers.
