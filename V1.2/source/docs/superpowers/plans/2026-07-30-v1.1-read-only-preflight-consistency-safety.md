# V1.1 READ_ONLY Preflight Consistency and Safety Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restore FAKE campaign Preflight and make one explicit V1.1 READ_ONLY hardware snapshot produce the single immutable, fully audited capture used by mapping, validation, sweep counting, and B0 freezing.

**Architecture:** `V11ApplicationService` owns a bounded token cache and is the only layer allowed to request a live capture. `ReadOnlyV11Gateway` performs one deadline-bound capture with a query-only DCA client, one audited VD1124 serial session, and read-only BERT calls; it creates a B0 only after every device and page restoration verifies. Downstream API calls require the snapshot token and use cached evidence without reconnecting hardware.

**Tech Stack:** Python 3.13, FastAPI, Pydantic, pytest, PyVISA, pyserial, UDP VIT BERT protocol, React 18, TypeScript, Zod, Vitest, Vite.
