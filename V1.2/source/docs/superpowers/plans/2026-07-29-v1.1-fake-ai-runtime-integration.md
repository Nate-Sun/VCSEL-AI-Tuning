# V1.1 FAKE AI Runtime Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Assemble a real, persistent, hardware-free V1.1 AI execution factory into the default FAKE runtime and prove the full HTTP optimization lifecycle.

**Architecture:** Add a deterministic in-memory FAKE plant and a cooperative `FakeV11AIExecution` adapter that obtains every decision from the existing pure `optimization/v11` API through `optimizer_bridge`. Persist one observation per executed candidate and the complete best state in the existing V1.1 SQLite store, reconstruct optimizer progress from those records on Resume, and let `PersistentV11TaskRunner` continue to own terminal B0 restoration and lifecycle transitions.

**Tech Stack:** Python 3.13, FastAPI/TestClient/Uvicorn, SQLite `TaskStore`, Pydantic, NumPy-backed V1.1 optimizer, pytest, React/Vitest/Vite.

- [ ] **Step 4: Implement the minimal complete bridge and plant**

Extend `V11OptimizerApi` and `load_v11_optimizer_api` with the public pure types.
In `fake_ai_execution.py`, implement:

```python
class FakeOptimizationPlant:
    def __init__(self, b0: B0Snapshot) -> None:
        self._b0_i2c = dict(b0.i2c_fields)
        self._b0_fir = tuple(b0.fir_taps)
        self._current_i2c = dict(self._b0_i2c)
        self._current_fir = self._b0_fir

    def apply_i2c(self, requested: Mapping[str, int]) -> dict[str, int]:
        if set(requested) != set(self._b0_i2c):
            raise ValueError("FAKE I2C candidate must match the B0 field set")
        self._current_i2c = dict(requested)
        return dict(self._current_i2c)

    def apply_fir(self, target: Any) -> tuple[int, ...]:
        self._current_fir = tuple(target.taps)
        return self._current_fir

    def read_dca_taps(self) -> tuple[tuple[float, ...], int]:
        norm = max(1, sum(abs(value) for value in self._current_fir))
        return tuple(value / norm for value in self._current_fir), 3

    def measure(self) -> dict[str, float]:
        i2c_delta = sum(
            (value - self._b0_i2c[name]) ** 2
            for name, value in self._current_i2c.items()
        )
        fir_delta = sum(
            abs(value - baseline)
            for value, baseline in zip(
                self._current_fir, self._b0_fir, strict=True
            )
        )
        return {
            "tdecq_db": round(2.8 - 0.02 * i2c_delta + 0.002 * fir_delta, 6),
            "er_db": round(5.4 + 0.01 * i2c_delta - 0.001 * fir_delta, 6),
        }

    def restore_b0(self) -> None:
        self._current_i2c = dict(self._b0_i2c)
        self._current_fir = self._b0_fir

    def is_at_b0(self) -> bool:
        return (
            self._current_i2c == self._b0_i2c
            and self._current_fir == self._b0_fir
        )
```

The deterministic metric surface may generate synthetic TDECQ/ER, but it must
never compare or rank them.
