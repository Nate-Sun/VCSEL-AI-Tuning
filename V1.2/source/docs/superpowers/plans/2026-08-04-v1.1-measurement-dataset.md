# V1.1 Optional Measurement Dataset Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an immutable `save_dataset` task option and a safe Sweep dataset recorder that produces same-acquisition NPY/PNG/JSON bundles in FAKE/replay without guessing LIVE FlexDCA commands.

**Architecture:** Persist the switch in the existing task JSON payload, rebuild it into `SweepPlan`, and select one `DatasetRecorder` when the executor is assembled. NoOp performs no extra reads; the enabled writer accepts only an explicitly frozen same-acquisition capture and atomically publishes evidence without raising hardware-control exceptions.

**Tech Stack:** Python, Pydantic/FastAPI, dataclasses, NumPy NPY, standard-library PNG/zlib/hashlib/JSON/filesystem APIs, SQLite JSON payloads, pytest.
