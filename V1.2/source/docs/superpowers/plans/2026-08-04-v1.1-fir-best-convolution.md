# V1.1 FIR Best-Convolution Implementation Plan

> **For agentic workers:** Execute each task in order with strict red-green-refactor TDD. Do not access real hardware, change worktrees, or merge the branch.

**Goal:** Make B1 and every later V1.1 FIR proposal convolve the latest accepted seven-tap BERT FIR with the current DCA TDECQ Equalizer taps, while retaining the latest accepted FIR after rejection and stopping after three consecutive misses.

**Architecture:** Keep the established formula implementation in `hardware/fir.py` and use `calculate_iterative_pass()` as the single V1.1 convolution dependency. Preserve `propose_first()`/`propose_iterative()` and persisted mode labels, but route both through one controller proposal path over `best_fir`. Update FAKE execution and replay to continue FIRST misses, and update the hardware adapter so invalid Equalizer data causes no FIR write.

**Tech Stack:** Python 3.13, Pydantic, pytest, SQLite-backed V1.1 FAKE/replay runtime.
