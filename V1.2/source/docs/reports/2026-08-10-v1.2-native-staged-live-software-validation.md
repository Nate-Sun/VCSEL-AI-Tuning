## 9. 进入真实硬件测试前后的顺序

软件门已经通过。真实硬件测试仍必须按以下顺序逐级放行：

1. READ_ONLY Preflight：确认设备身份、B0、DCA 状态，只读不写。
2. 单次非基线 FIR：只使用合法公式生成值，写入后精确 readback，再恢复并验证 B0。
3. 真实 `PILOT_3`：强制保存 Dataset，确认三轮证据和最终恢复。
4. 真实 `FAST24`：只有 PILOT gate 通过后才进入，任何身份变化、DCA 异常或恢复失败立即停止。
5. 在单独通知后执行两小时稳定性测试。
